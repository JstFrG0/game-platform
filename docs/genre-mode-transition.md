# 玩法类型与游玩模式：仅增加过渡动画

保留两页的布局、星座形状与姿态、标题和控件、选中效果以及通信阵列几何。光球路径、页面位移、背景和拖尾沿用现有实现。

- 出发前读取原有 SVG 星点在当前缩放、平移与三维姿态下的实际位置和颜色，缓存为画布局部坐标。过渡期间不逐帧读取 DOM。
- 原星座连线和名称淡去，星点沿由 ID 决定的不同弧线汇入现有共享光球。所有星点在进度 2.28 前抵达，早于原页面离开与光球移动；不再将整个星座按钮缩回核心。
- 选中状态与筛选草稿始终保留。已有的点击选中/取消光点动画在切页时按原逻辑收束，不叠加计时任务。
- 光球在原进度 2.76 落位后，由同位置的临时画布画出一圈轻柔扫描波；进度 2.84 起调用原通信阵列绘制逻辑展开，3 时达到原有完整状态。未选具体模式时沿用原默认阵列。
- 扫描波不会新增通信线，也不修改环带、模式分配或组合布局。`modeRelay.js` 与 `modeRelayCanvas.js` 保持原文件。
- 星点轨迹和扫描波由同一连续页面进度计算，可停住、反向；结束时撤下星图过渡层并清空扫描波。返回页面后恢复现有漂浮与操作。
- 窗口尺寸变化后重新测量星点；直接打开游玩模式也支持反向返回。系统减少动态效果时跳过新增特效；画布不可用时星图回退到原有收拢过程。
- 不增加 API 请求、运行依赖，也不修改数据库或备份规则。

纯函数测试位于 `frontend/tests/genre-mode-effects.test.mjs`，覆盖收束完成顺序、弧线与尾迹、颜色/缩放/搜索暗化、暂停及反向、扫描波与阵列展开先后、空画布。浏览器回归需检查两页端点原样、当前平移和缩放、直接反向打开、确认/取消、其他筛选页和窄窗口。
