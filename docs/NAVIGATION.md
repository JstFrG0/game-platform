# 列表滚动位置

从游戏列表进入详情页时，按列表完整 URL 记录滚动位置，包括搜索、筛选、排序和页码。

从详情页点击“返回目录”，或使用浏览器后退返回该列表时，在列表请求结束、Vue 完成渲染后恢复滚动位置。浏览器提供的历史位置优先于页面内记录。新搜索、筛选和翻页仍使用原有的顶部定位行为；不恢复其他筛选列表的位置。

位置记录保存在当前页面运行期间的内存中，最多保留 50 个列表地址。不额外缓存游戏数据，不写入数据库或本地存储。整页刷新不保证保留按钮返回所需的内存记录。

快速离开正在恢复的列表时，旧恢复任务会取消，避免在新页面加载后发生错误滚动。列表加载失败也会结束等待，用户可继续重试或导航。

实现：`frontend/src/catalogScroll.js`、`frontend/src/main.js` 和列表页的渲染完成通知。单元测试位于 `frontend/tests/catalog-scroll.test.mjs`。
