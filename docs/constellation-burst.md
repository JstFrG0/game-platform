# 玩法类型：从光点中迸发的星座

- 平台切到玩法类型时，光球先抵达星图中心；切换进度超过原有落位点后，所有星座同时从光点内部向外迸发。
- 星座先小后大，前段扩散较快，末段轻微舒展后收稳。中途停止或反向滚动会保持或回收同一条轨迹。
- 直接从主页面打开玩法类型，也使用同一爆发过程。减少动态效果时直接显示完整星图。
- 根据视野尺寸分布到整个场地，位置加入受约束的偏移；每个类型的随机姿态由 IGDB ID 固定。相同类型与相同视野尺寸下，重新打开、搜索、选中或反向切换均不洗牌。
- 图案绕竖直轴倾斜不超过 34°，绕屏幕法线顺逆时针偏转不超过 18°。飞出时有额外姿态变化，最后落稳。
- 名称是图案之外的独立层，始终水平放在图案下方，完整名称也可通过悬停查看。图案倾斜不影响名称和点击区域。
- 桌面视野中尽量完整呈现全部星座；狭窄或类型较多时保留合理的字号和间距，通过拖动、查找和“适应”访问其他区域。
- 多选、全部类型、查找与粉碎清除、确认/取消、星空拖动视差、两组斜向光球拖尾及文字从底部入场保持已有操作方式。

## 落位后的漂浮与选中状态

- 落位后只有星座图案轻微漂浮，周期按类型固定在 14～22 秒之间，各自有不同的启动延迟、方向和轻微姿态变化。水平位移不超过 2.6 像素、竖直位移不超过 3 像素，名称和点击区域保持固定。
- 选中后，在星座附近显示稀薄光晕与局部弧线，星点和图案连线柔和变亮，移除名称旁的勾选标记，改为覆盖整个星座及周围空间的持续星尘。选中时细粒从星座内部的分散位置轻轻铺开，随后在内外区域缓慢游动；取消选中时淡出。不再从中心光球拉出长线。
- 鼠标悬停或键盘聚焦某个星座时暂停该图案漂浮；拖动星图、页面隐藏时暂停全部漂浮。右下角有独立的暂停/恢复按钮。
- 页面切换和爆发过程中不播放漂浮，保持中途暂停与反向回收的既有轨迹。系统减少动态效果模式不播放漂浮。
- 不改变多选草稿、确认/取消或筛选结果。

## 持续的选中星尘

- 每个星座固定 24 个细粒，按面积均匀分布在扩大的椭圆区域中，同时覆盖星座内部、线条之间和外侧，不再按星点分组。位置由类型 ID 固定，不会重新洗牌。
- 外侧覆盖范围较星座图案的包围区域向两侧扩展约 30 个 SVG 单位、上下约 22 个 SVG 单位。细粒与图案共用姿态层，保持倾斜和缩放关系，名称不参与移动。选中后先用约一秒铺开，再以 6～11 秒的不同周期小范围游动和柔和明暗变化。细粒持续存在，不会全部消失，也不会持续增加数量或飞离星座。
- 光晕、星点亮度和 aria-checked 继续表达选中状态，名称保持水平，不再显示勾选标记。
- 暂停/恢复按钮、悬停、键盘聚焦和拖动同样控制细粒的持续漂浮。页面隐藏或切换中途暂停动画，关闭页面移除临时粒子层。
- 取消选择或选择“全部类型”后淡出粒子层；快速反复切换选中状态也保持固定数量。
- 系统减少动态效果模式显示静态细粒，不播放散开或漂浮动画；系统高对比度模式使用名称双下划线和 aria-checked 作为选中反馈。

## 光点传递与抵达增强

- 点击选择后立即记录筛选草稿和 `aria-checked`，星座外观暂时维持未激活状态。一个直径 5px 的圆形光点从共享核心飞往星座图案中心，飞行约 640～920ms，距离越远略慢。拖尾沿真实飞行向量的反方向延伸，去程和回程都适用于任意斜向，不沿用页面切换的固定方向。
- 光点抵达后消失，星座开始激活，并用约 1.44 秒柔和增强再回落。峰值图案亮度只比常态激活提高约 22%；星点光晕和连线稍微增强，不改变名称亮度、位置或角度。
- 抵达时保留原有 24 个持续细粒，同时额外散出 18 个更广的细粒。额外细粒向扩大的内外区域铺开，较远细粒逐渐消失；原有 24 个细粒保持同一批 DOM 元素，随后继续常态漂浮。不会在增强结束后重新生成常态星尘。
- 取消选择时立即开始恢复未激活外观，持续细粒沿原有淡出效果消失。约 100ms 后，小光点从星座返回核心；回程结束后移除。选择“全部类型”也分别收回已选星座的光点。
- 每个类型按 IGDB ID 保存独立时间线，每个类型最多一个飞行光点和一组临时星尘。新增选择不会重置其他星座；快速反选同一个星座以最后一次操作为准。
- 光点与星图共用坐标系，拖动、缩放时保持相对位置；名称和点击区域仍不受增强效果影响。尺寸改变或离开当前页时，移除临时特效并直接呈现草稿对应的状态。
- 暂停按钮冻结正在进行的光点和增强动画，恢复后继续；暂停期间的新操作直接更新静态状态。隐藏标签页时停止计时，返回后继续，不追赶离开期间的时间。
- 确认无需等待特效；取消仍丢弃草稿。关闭时清理时间线，重新打开时已选星座直接显示常态激活状态，不重播飞行。不会增加 API 请求。
- 系统减少动态效果时直接更新静态选中状态，不播放飞行、增强或临时粒子；运行中切换该偏好也立即清理特效。

验证：`frontend/tests/constellation-signal.test.mjs` 检查抵达前后顺序、返回延迟、各方向拖尾、并行与反选、长帧限速，以及有限数量的扩散星尘。浏览器验证确认视觉延迟不影响草稿、常态粒子身份保留、暂停/恢复、拖动缩放、立即确认/取消和窄窗口布局。
