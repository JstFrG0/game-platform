# 前端设计约定

用户偏好：炭灰深色背景、蓝色强调、封面卡片；简约、信息集中、减少装饰性小字。

1. 页面优先展示游戏资料和可执行操作。不要加入宣传口号、英文装饰副标题、重复统计或填充说明。
2. 一个信息组放在一个明确区域。基本信息、评分、简介分别集中展示，不拆成零散的小面板。
3. 必要标签用正常可读字号。保留筛选标签和评分来源，避免无标签数字造成歧义。
4. 使用清晰的标题、留白和少量分隔线建立层次。减少浮标、悬浮文案和重复卡片说明。
5. 别名、来源ID、采集时间等补充资料放入可展开区域。原始数据仍保留在API和数据库中。
6. 加载失败、空结果、缺少评分等功能状态保持明确，不以省字为由隐藏问题。
7. 使用系统字体，保留键盘焦点、语义标签和响应布局；不依赖远程字体。
8. 新模块沿用这些规则，不把内部技术信息放进主要浏览流程。
