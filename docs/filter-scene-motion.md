# 筛选特殊页的默认切换约定

用户于 2026-10-21 确定：后续筛选特殊页默认使用以下两种效果，有特例时另行指定。

1. 目标页的文字组件从屏幕最下方之外向上逐渐入场，包括标题、当前选择、查找栏和视图操作文字。不要在原位置突然出现，也不要只在页面内部做很短的位移。
2. 共享光球带柔和的斜向拖尾，按页面切换形成的视觉运动决定方向。即使光球锚点暂时静止，周围页面移动形成的相对运动仍可产生拖尾；切换暂停后淡去。

## 已确认的拖尾方向

| 切换 | 光球拖尾 |
| --- | --- |
| 发售年份 → 游戏平台 | 左上 |
| 游戏平台 → 发售年份 | 右下 |
| 游戏平台 → 玩法类型 | 右上 |
| 玩法类型 → 游戏平台 | 左下 |
| 玩法类型 → 游玩模式 | 右上 |
| 游玩模式 → 玩法类型 | 左下 |

年份与平台、玩法类型与游玩模式的斜向以竖直方向为基准偏转约 20°，维持柔和短尾与末端渐隐。年份与平台之间，向下切换时光球视觉上从左上移到右下，返回时相反。

平台 → 玩法类型采用新的穿孔下落路径，拖尾按真实轨迹指向运动后方。默认布局中通常朝右上，反向朝左下；拖动基座改变出发位置后，拖尾会相应调整。开口期间页面保持静止，不显示飞行拖尾。

后续特殊页默认沿用平台与玩法类型之间的方向；有类似年份与平台的不同视觉轨迹时单独指定。文字入场仍遵循上述默认约定。

切换仍由同一个连续进度控制，滚轮可停在中间并原路反向。不要给文字、光球或主体各自启动无法回退的计时动画。

保留各页主体自己的生成逻辑：年份球体收缩、粉化与重建，平台枝干回流与原基座开口，玩法类型星座展开。共用默认效果不替代这些主体动画。

减少动态效果模式直接到达完整可操作的端点，不显示拖尾。入场不改变草稿、确认、取消、筛选或键盘焦点的语义。

当前平台 → 玩法类型先沿已挂载分支回流亮光，再在原菱形基座中央展开缺口；空基座跳过回流。开口期间基座与页面静止，光球开始穿孔下落后镜头和背景才跟随；基座及平台标签正确遮住途经的光球，洞口内连线临时裁去。整个 genre-shell 从屏幕下方上移，星座在光球到达后展开。常态基座和科技树样式保留，反向滚动严格回放相同路径。细节见 `platform-genre-descent.md`。

玩法类型 → 游玩模式先将原 SVG 星点解构，沿弧线汇入共享核心，再将 mode-shell 按原路径从屏幕下方上移。光球到达后先发出扫描波，再展开原有组合通信阵列。模式页的文字、主体与背景进度可停留和原路反向；选择项不随阵列组合移动。两页布局和常态样式保留，详见 `genre-mode-transition.md`。
