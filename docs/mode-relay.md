# 游玩模式通信星阵

点击选项多选，再次点击取消；默认“全部模式”不增加模式限制。主光球不移动到选项中，多个模式围绕同一个核心逐步组装通信阵列。文字与选项点击区保持固定。

### 多模式布局

各模式使用统一投影下的独立环带。单人轨道在公共通道方向留有实际开口，分屏和合作共用两条核心通道与中继节点，公共连接只绘制一次。合作分支位于两侧的独立扇区，分屏局部弧线为这些分支留出接口。多人、大逃杀、大型多人依次使用更外侧的专用轨道，短连接限定在各自环带内，未来模式预留独立外层。

组装动画沿已分配的轨道展开，取消沿原轨道收回。生成中的圆环不会径向穿过其他模式；原有公共连接也不会重复叠画。四种及以上模式仍会按组装权重平滑展开，所有环带使用同一缩放和投影，所以展开过程中保留无交叉关系。其他模式的独立轨道在多选期间保持分配，反复选择不会重新编号；光点沿可见的开口弧线移动。

密集组合适当扩大主体，绘制比例同时参考真实 Canvas 尺寸与完整轨道、节点光晕边界。窄屏自动约束尺寸，避免为了放大裁掉外环；取消模式时从当前组装权重平滑收拢。点击区、筛选 ID 和“全部模式”语义不变。

几何验证覆盖六种已知模式的全部 64 种选择，在不同信号时刻检测线段、曲线与装饰轨道；还覆盖 1,344 个逐项新增/取消的中间状态，以及随机混合权重和未知模式。仅允许在明确的通信节点连接端点，禁止无关线条相交或整段重合。检测辅助代码位于 `frontend/tests/mode-planarity.test.mjs`。

## 结构与数据

- 单人：独立轨道与终端。
- 多人：分散节点与交替通信。
- 合作：与共同核心协同通信；与分屏组合时逐渐分成左右两组。
- 分屏：左右对称的通信通道。
- 大型多人：外围中继层与分层信号。
- 大逃杀：向内汇聚的节点。其他新增或暂时没有名称的模式也保留可选择的模块，不硬编码成只有五个选项。
- 选项直接来自全库 `game_modes` 字典，使用真实 IGDB ID；中文名称只用于显示。已保存但不在字典里的 ID 也保留，避免打开后丢失选择。

点击只更新共享草稿。确认将四个特殊页的草稿一次同步到侧栏；取消、右上角关闭或 Escape 丢弃整次草稿。确认后仍需点击“应用筛选”才查询游戏列表。

同一模式大类内为 OR：选择单人和合作，支持任意一种即可命中。同一游戏只返回一次。与年份、平台、玩法类型等大类取交集。`mode_ids` 接受逗号分隔的整数，最多 100 项；兼容旧 `mode_id`，两者合并。全库关键词搜索继续忽略所有浏览筛选。地址、翻页、返回浏览状态均保留多选。

## 页面切换

顺序为发售年份 → 游戏平台 → 玩法类型 → 游玩模式。滚轮可停在中途并反向；W/S、上下键、PageUp/PageDown 逐页切换，底部可直达。输入框键入文字不会切页。

玩法类型 → 游玩模式时，星座解构为原有星点，沿不同弧线汇入光球，原页文字上移退出，新页文字从屏幕下方进入；共享光球沿测量到的锚点移动，带右上方短拖尾。光球落位后先发出扫描波，再展开原有通信阵列。反向采用同一路径回放，拖尾转向左下；背景星空连续移动，紫色星云逐渐过渡为稀薄蓝色。布局、星座常态样式、通信轨道与组合几何不变，详见 `genre-mode-transition.md`。

页面切换使用同一个连续进度，不能为主体、标题、光球另开不可回退的计时动画。单个模式的点击组装从当前权重向新目标推进，快速点击从当前位置反向，不重建其他模块。合作与分屏之间的位置变化通过同一权重连续插值。

## 性能与操作

无新增运行依赖。星阵使用轻量 Canvas；主光球继续由 FilterSpace 的共享层绘制，Canvas 只绘制光晕，避免重复核心。使用父层已有动画时钟；隐藏页面、关闭弹窗或切到其他场景时停止星阵绘制。暂停动态停止持续信号，模式选择仍可使用。系统“减少动态效果”直接呈现完整静态结构并保留键盘点击。

不要把视觉组合理解为自动更改筛选语义。例如合作＋分屏的双侧协同阵列，仍表示合作或分屏任一匹配。
